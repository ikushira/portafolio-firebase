# 📋 App de Tareas con Firebase

Aplicación web moderna con autenticación de usuarios y sistema CRUD (Crear, Leer, Actualizar, Eliminar) utilizando Firebase como backend. Cada usuario gestiona sus propias tareas en tiempo real de forma segura.

---

## 🚀 Características

* 🔐 Autenticación de usuarios (registro, inicio de sesión y cierre de sesión)
* 📋 CRUD completo de tareas
* 👤 Datos separados por usuario mediante UID
* ⚡ Sincronización en tiempo real con Firestore
* 🎨 Interfaz moderna, responsive y en modo oscuro
* 🔄 Manejo de estado de sesión en tiempo real

---

## 🛠 Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla)
* Firebase Authentication
* Firebase Firestore

## 📌 Descripción técnica

La aplicación implementa autenticación de usuarios mediante Firebase Auth y un sistema CRUD conectado a Firestore. Cada documento en la base de datos está asociado al `uid` del usuario autenticado, garantizando aislamiento y seguridad en los datos.
